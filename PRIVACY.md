# Privacy Policy — ytf

_Last updated: 10 November 2026_

ytf ("the app") is a personal, single-user production tool. It is operated by the owner of one YouTube channel to
upload, schedule and analyse videos on **that owner's own channel only**. It is not offered to the public, and no
other person can sign in to it.

## What the app accesses

When the channel owner authorises the app through Google OAuth, it uses YouTube API Services to:

- upload videos, thumbnails and caption tracks to the owner's channel and add them to the owner's playlists;
- read and update the privacy status and scheduled publish time of videos it uploaded;
- read the channel's YouTube Analytics data (views, watch time, retention, subscribers gained) for its own videos.

The app does not access any other user's data, comments or private messages.

## How data is stored and used

- OAuth tokens are stored encrypted on the owner's own server and are never written to logs or shared.
- Analytics data is used only to decide which topics to make next. Raw API data is kept for at most 30 days and is
  refreshed or deleted after that, as required by the YouTube API Services Developer Policies.
- No data is sold, shared with third parties or used for advertising.

## Third-party terms

By using this app you agree to be bound by the YouTube Terms of Service:
https://www.youtube.com/t/terms

Google's handling of data is described in the Google Privacy Policy:
https://policies.google.com/privacy

## Revoking access

Access can be revoked at any time from the Google security settings page:
https://security.google.com/settings/security/permissions

After revocation, the app deletes stored tokens and any stored API data within 7 days.
