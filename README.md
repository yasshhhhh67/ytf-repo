# ytf

A small, self-hosted production pipeline for an educational "AI & Technology Explained" YouTube channel.
It researches topics, writes evidence-checked scripts, narrates them with an offline voice, renders programmatic
explainer animations, runs automated quality checks, and uploads videos for the owner's approval before publishing.

Everything runs on free-tier cloud machines. No paid APIs.
